## Trust Boundaries

AMBO is an offline batch/CLI pipeline: no network service, no authentication surface, no session,
a single local user, and a single writer per file. The only boundaries that genuinely exist in
this plan's scope are the git history boundary (what leaves the machine on `git push`) and the
local filesystem boundary between the repository and the private drop.

| Boundary | Description |
|----------|-------------|
| working tree → git history / origin | Anything committed and pushed is permanent under EB-082; a mistake cannot be un-pushed by rewriting |
| private drop → repository | `AMBO_PRIVATE_DROP` contents must never cross into a tracked file (no drop path is referenced by this plan) |
