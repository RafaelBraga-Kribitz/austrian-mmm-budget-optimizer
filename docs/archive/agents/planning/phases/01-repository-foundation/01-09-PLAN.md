## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| repository → GitHub Actions runner | CI executes repository code plus third-party actions on a hosted runner; the workflow file is the only thing that decides what runs |
| third-party actions → runner | Each `uses:` entry executes code this project did not write |
| Chocolatey package feed → Windows runner | The Windows leg installs GNU Make from a community feed at job time |
| git history → the layer-order predicate | GB-501 and GB-502 are ancestry claims, so a rewritten history would silently invalidate them |
