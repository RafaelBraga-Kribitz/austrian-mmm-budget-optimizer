  <action>
Create `scripts/leak_scan.py`.

Open with a module docstring that states the scope decision plainly, because the precision of this
gate is the reason it will still be trusted in Phase 6. Say what is in scope — the three pattern
classes below — and say what is deliberately not: anonymized euro figures under `exports/`, which
are committed by design; euro figures anywhere in `docs/`; and any general secret-shaped string
outside the scoped paths. State that widening the set is Phase 6 work, tracked on the risk register.

Define three pattern classes as module constants so a reader can audit them without reading the
control flow.

`PRIVATE_DROP_PATTERNS` covers the resolved drop path in whichever forms it can appear: the literal
resolved path from `load_settings().private_drop` when it is set, matched case-insensitively with
both separator styles normalized; plus a generic shape for a Windows or POSIX absolute path
adjacent to the environment variable's own name, which catches a path pasted into a committed file
even on a machine where the variable is unset. This class scans every tracked text file.

`CONTACT_PATTERNS` covers email, URL and phone shapes. Scope it by path: it applies only under
`data/real_anon/` and `reports/ingestion/`, held in a `CONTACT_SCAN_ROOTS` constant. Write the
email pattern to require a local part, an at sign and a dotted domain with a plausible top-level
label; write the URL pattern to require a scheme; write the phone pattern to require an Austrian
international or national prefix followed by a digit run, rather than matching any long digit
sequence, since a spend figure is a long digit sequence.

`CURRENCY_LITERAL_PATTERN` covers a currency-formatted literal and applies only to notebook files,
where output cells can carry values that never belonged in the repository and where nbstripout
already runs.

Define `Finding` as a small immutable record carrying path, line number, pattern class name and a
short hexadecimal digest of the matched text. Nothing else. There is no field that could hold the
match, so no code path can print it by accident — that is the point of the shape.

`scan_tree(root, blocklist=None)` walks tracked files via `git ls-files`, skips files git treats as
binary, applies each pattern class within its scope, and returns a list of `Finding`. When a
blocklist is supplied, each of its values is matched as an additional pattern class across the whole
tree.

`scan_staged()` reads `git diff --cached -U0` and applies the same classes to added lines only, so
the pre-commit hook is fast regardless of repository size.

`main(argv)` parses three flags — a full-mode flag, a staged-mode flag, and a root override —
rejects any other argument or a combination of full and staged with exit code 2 and a usage message
on the error stream. Full mode resolves `load_settings().private_drop` and reads `blocklist.txt`
from beneath it, one distinctive value per line; when the drop is unset or the file is absent it
prints an explicit notice that the blocklist was unavailable and continues with the subset, exiting
on the subset's result. This is the same vacuously-correct shape D-17 applies elsewhere: the check
runs and reports what it could and could not do, rather than being skipped. Findings print one line
each as path, line number, pattern class and hash prefix, and `main` returns 1 when the list is
non-empty and 0 when it is empty.

Keep the whole-tree scan under 10 seconds: compile every pattern once at module import, read each
file once, and skip files the binary check excluded rather than decoding them.

<threat_model>
## Trust Boundaries

This plan builds the project's secrets-handling controls, so its trust boundaries are the real
ones rather than nominal. AMBO remains an offline batch pipeline: no network service, no
authentication, no session, one local user.

| Boundary | Description |
|----------|-------------|
| private drop → repository | The scanner and the hook exist to police exactly this crossing; `AMBO_PRIVATE_DROP` contents must never reach a tracked file |
| working tree → git history / origin | A commit is permanent under EB-082, so the hook must block before the commit object exists, not after |
| scanner findings → CI logs / terminal | A finding is itself an output channel; echoing a match would leak the value the scan exists to protect |
| pre-commit hook repositories → local environment | Hook repositories execute code at commit time; a moving branch reference would let that code change without review |

Tests prove all three modes and both scoping directions |
