## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| process → filesystem (`data/synthetic/`) | The only write boundary in the phase; nine committed-by-design artifacts are produced here. |
| committed tree → regenerated tree | The determinism gate compares them; this is the integrity check the whole Layer P reproducibility claim rests on. |
| `argv` → CLI | User-supplied arguments select a scenario and an output directory. |

Explicitly **not applicable**: **V2 Authentication**, **V3 Session Management**,
**V4 Access Control**, **V6 Cryptography** — no user-facing surface, no principal, no

guarded by `tests/unit/test_no_requests.py`; this CLI performs local file I/O only.
