`generate_spend(cfg: ScenarioConfig, rng: np.random.Generator, weeks: pd.DataFrame) -> pd.DataFrame`.

This promotes `03_MODULES.md` §2.2's two-argument signature to three arguments. Rationale to
record in the contract entry and the plan SUMMARY: SPEC-01 §3's seasonal planning multipliers
need the Advent and spring flags, AD-020 forbids recomputing those windows, and the
Functional-Core/Imperative-Shell rule forbids this module doing I/O — so the week-index frame
produced by `dgp.week_index` is injected rather than read here.

Implementation, per channel `c` in `SPEC_CHANNEL_ORDER`, in exactly this order:

1. **Mean vector.** Start from `pattern.mean` repeated T times. Multiply elementwise by
   `1 + pattern.advent_factor * advent_flag + pattern.spring_factor * spring_flag`. Then, if
   `pattern.pulse_every` is set, multiply the weeks where the 1-indexed `t % pattern.pulse_every == 0`
   by `pattern.pulse_multiplier` (first pulse at week 6 for `pulse_every = 6`; state this
   convention in the docstring, and note that WBS T-102's `t mod 6 == 0` and Guide §1.3's
   `(t-1) % 6 == 5` are the same weeks under 1-indexing).
2. **Draw.** One call: `rng.normal(loc=mean_vector, scale=pattern.sd)`. Always draw the full
   length-T vector, including for flighted channels whose non-burst weeks are discarded — this
   keeps stream consumption independent of schedule length.
3. **Flighting mask.** If `pattern.burst_length` is set, build the boolean mask of weeks
   covered by the authored spans (for each `(iso_year, start)` in `burst_starts`, the weeks
   `start .. start + burst_length - 1` of that ISO year), and set every uncovered week to 0.0.
4. **Floor clamp.** `np.maximum(values, pattern.floor_eur)` when `floor_eur` is set, otherwise
   `np.maximum(values, 0.0)` — spend can never be negative. Apply the clamp only to weeks the
   flighting mask kept, so a zero week stays exactly 0 rather than being lifted to the floor.
5. **Round.** `round_half_up(values)` imported from `ambo.simulate.dgp` — the single home of
   the convention (A-8). Result dtype `int64`.

Return a `pd.DataFrame` indexed by the `t` column of `weeks` (1..T), with columns in
`SPEC_CHANNEL_ORDER`. Raise `SimulationError` if `weeks` has a row count other than
`cfg.weeks`, or if any burst span in the config falls outside the frame's `(iso_year, iso_week)`
set — the config validator already rejects out-of-window schedules, so this is the
defence-in-depth restatement `03_MODULES.md` §2.2 asks for.

Append the `### src/ambo/simulate/spend_patterns.py` entry to `docs/MODULE_CONTRACTS.md` in
the same commit: `Purpose`, `Public API` with the full signature, `Invariants` (single
injected generator; fixed six-call taxonomy draw order; four-step order; integers ≥ 0; no
scenario branch; no I/O), `Failure modes` (`SimulationError` conditions), `Testing`.
