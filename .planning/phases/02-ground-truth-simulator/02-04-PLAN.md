the closed-form test alone can pass against certain reversed implementations.

`adstock_recursive(x: np.ndarray, lam: float) -> np.ndarray` — validate first: `x` is 1-D,
all finite, all non-negative; `0.0 <= lam < 1.0`. Each violation raises `SimulationError`
naming the offending value and the expected domain. `lam == 1.0` is rejected explicitly
because the closed form `x/(1−λ)` diverges there. Then compute with a plain forward loop over
`t`: `a[0] = x[0]`; `a[t] = x[t] + lam * a[t-1]` for `t >= 1`. Do not vectorize with

explicitly, and a vectorized form is where trap T-2 (direction reversal) hides. The docstring
states: pure, O(T), causal, `a_0 = 0`, and that `a_t` depends only on `x_{<=t}`. An empty
input returns an empty array; a valid `ScenarioConfig` can never produce one because `weeks`
is constrained to {156, 104, 78}, so this is a documented total-function property rather than
a reachable case.

`hill(a: np.ndarray, K: float, s: float) -> np.ndarray` — validate `a` all finite and
non-negative, `K > 0`, `s > 0`, each violation raising `SimulationError`. Compute
`a**s / (a**s + K**s)`. The docstring states that `hill(K, K, s)` is exactly 0.5 for every
`s > 0` because numerator and denominator differ by exactly a factor of two in floating point,
and that `hill(0, K, s)` is exactly 0.0.
