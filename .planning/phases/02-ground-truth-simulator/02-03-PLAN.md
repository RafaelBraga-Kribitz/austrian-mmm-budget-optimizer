Pure functions (no I/O beyond the single seed read in `main()`):

- `read_windows(path) -> dict[int, dict[str, tuple[int, ...]]]` — per ISO year, the flagged week numbers for `advent`, `schulbeginn`, `spring`, plus that year's total ISO week count.
- `prorate(full_count: int, covered_weeks: int, weeks_in_year: int) -> int` — `floor(full_count * covered_weeks / weeks_in_year + 0.5)` (round half **up**, per BP-D-09). Do not use `round()`, whose banker's rounding would turn 2.5 into 2.
- `black_friday_week(iso_year, windows) -> int` — the ISO week containing the 4th Friday of November of that ISO year, computed with `datetime.date` and `isocalendar()`; do not hand-roll week arithmetic.
- `anchored_promo_weeks(iso_year, windows, covered) -> tuple[int, ...]` — the Black Friday week, then the two advent-flagged weeks nearest Dec 24 that are not the Black Friday week (that is, the last two of the four flagged weeks, falling back to the next-nearest if one collides with Black Friday), then two weeks inside the spring window. Include an anchor only if its week is inside the scenario's covered span for that year.
- `anchored_burst_starts(channel, iso_year, windows, covered) -> tuple[int, ...]` — with `A` = the first advent-flagged week of the year and `S` = the first schulbeginn-flagged week: for `print_regional`, `(A, A + 2, S)`; for `radio`, `(A - 3, A)`. Include a start only if its whole span lies inside the covered span. Comment the radio rule: two 3-week bursts cannot both fit inside a 4-week Advent window without overlapping, so the pair is authored as a lead-in burst plus an in-Advent burst, both anchored to the Advent demand peak — record this reading for `docs/BUILD_LOG.md`.
- `spread_placements(rng, needed, forbidden, span, length) -> tuple[int, ...]` — draw `needed` non-overlapping start weeks from the covered span, rejecting any start whose span intersects `forbidden` (already-placed spans in the same channel) and, for promo weeks, preferring non-adjacent picks. Deterministic given `rng`. Sort the result ascending before returning.

`main(argv: list[str] | None = None) -> int` — `argparse` with one optional flag
`--scenario {s_a,s_b,s_c,all}` (default `all`); reads the seed once; for each requested

`if __name__ == "__main__": raise SystemExit(main())`.

The script writes no files — its output is copied by hand into the YAMLs in Task 2, which
