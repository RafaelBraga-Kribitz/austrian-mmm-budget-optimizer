phases read directly and the reason "the model recovered ROAS" is a checkable claim.

Purpose: `truth.json` is this phase's most downstream-load-bearing output. Phase 5's VR-3xx
recovery gates and Phase 8's DC-401 optimizer-recovery gate both read it. Two design points
matter beyond SIM-075's completeness requirement. First, SPEC-01 §8's grid note (which

formally stable rather than incidentally stable.

curve evaluator, per 02-RESEARCH.md's recommendation), and `tests/unit/test_truth.py`.

unbounded at the origin) — state the branch in the docstring. Note in the docstring that this
is truth-side and uses SPEC-01's raw-recursion steady state, never the model's normalized
one (BP-D-16).
