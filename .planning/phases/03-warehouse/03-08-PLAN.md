Create `scripts/export_marts.py` as a registry-driven writer.

The registry is a module-level dict keyed by output filename, one entry today:
`mmm_input_weekly.csv`. Each value is a small frozen specification carrying a reader callable, the
ordered column list, the per-column dtype casts to apply before writing, and the sort keys. The
`mmm_input_weekly.csv` entry reads every layer from `ambo.common.db.read_mmm_input`, iterating the
layers returned by `read_dim_layer` rather than hard-coding three names, concatenates them, and sorts
by layer then week_start. Its column list is the mart's own seventeen columns, obtained from the frame
`db.py` returns — do not restate them here, since `db.py` already derives them from the single
authored home (D-08). The internal structure of this dict is Claude's Discretion under D-03; what is
not discretionary is that Phase 8 and Phase 9 must be able to add
`allocation_scenarios.csv`, `attribution_gap.csv` and the rest by adding a dict entry, never by
adding a second script or a second float-formatting path (T-205 AC-2).

Reuse the simulator's byte-stable atomic write verbatim rather than reimplementing it: temp file
named with the process id, opened with `newline=""`, written with index off, empty NA
representation, a six-decimal fixed float format, and an explicit line-feed terminator, then
`os.replace` onto the destination, with the temp file removed on any exception. Six decimals is D-04
and matches what the simulator already writes; pandas' default float repr is a library implementation
detail, and a minor version bump could rewrite every line of a committed file and turn plan 03-09's
diff-check red for a reason unrelated to the warehouse. Cast `week_start` to a `YYYY-MM-DD` string and
the integer-valued columns to a nullable integer dtype before writing, exactly as `_write_media_csv`
does, so an integer never renders with a decimal point and a NULL never renders as zero.

Resolve the output directory through `load_settings().paths.exports` — never a hard-coded path.

Give the script an argparse CLI with an accurate `--help`, an importable `main()` that tests can call,
and no side effects at import (03_MODULES §9's all-scripts rules). Accept an optional positional
argument naming which registry entries to write, defaulting to all of them, so a later phase can
regenerate one file without rebuilding the rest.

Add a module header comment recording D-05, in the shape of `platform_bias.py`'s one-line
downstream-concern note. It must state: this file is committed by design (SPEC-08 §2, EB-081) because
Phase 9's DL-1 probe compares regenerated output against it; once Phase 6 flips `layer_r_present`,
