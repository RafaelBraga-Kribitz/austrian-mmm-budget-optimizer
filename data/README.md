# Data

## data/synthetic (Layer P)

Generated by `python -m ambo.run layer_p` from the `synthetic` block of
`src/ambo/configs/layer_p.yaml`. Every parameter of the data-generating process is
written to `truth.json`; `weekly.csv` holds spend per channel, revenue, the public
holiday indicator and the platform-reported revenue for the online channels;
`true_contributions.csv` holds the true weekly contribution of each channel. Seeded
and deterministic. No real advertiser is behind these numbers.

## data/layer_r (Layer R)

Public demo data; a real-data swap-in is planned. No Austrian client data was used.

report ratios and shares rather than euro amounts.
